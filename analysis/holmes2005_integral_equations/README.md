# Holmes (2005) integral equations

Moved to the code repository cited by paper 1: `tkf-mixdom/tkf/holmes2005/`
(github.com/${REPO_OWNER}/tkf-mixdom; published as evoldoers/tkf-mixdom). It holds the proof
that paper 1's closed forms solve the corrected integral equations (8)-(17) of the
Holmes (2005) supplement, the sympy checks, and a note on the DART implementation.

Paper 1 summarises it in Appendix C. The correction request to Bioinformatics is
drafted in `molbiolevol-paper/holmes2005-correction/` (not published).
